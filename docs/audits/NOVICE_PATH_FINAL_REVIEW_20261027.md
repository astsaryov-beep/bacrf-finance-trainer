## Проверки и пределы

Полный штатный маршрут с чистого прогресса: 96 завершений, 309 основных и 204 дополнительных MC, 7 перезагрузок с продолжением, экспорт-импорт 513 ответов, экзамен 25 открытых / 25 настоящих MC. Браузер использует готовые ответы: это техническая проверка, а не результат ученика.

Это редакционное моделирование пути новичка, не эксперимент с реальными учениками. Сложность и различающая способность заданий не измерялись на студенческой выборке. Исторические ряды не реконструированы полностью; правовые исключения проверялись адресно на 27.10.2026. Открытые ответы оцениваются самим учеником по рубрикам. Известный формат экзамена воспроизведён, точный билет неизвестен.

T-06 не выполнялась и остаётся только по отдельной команде. Снятие beta/T-07 требует отдельного принятия пользователем. Новые материалы преподавателей и обратная связь настоящих учеников — вход для дальнейших адресных исправлений; обязательных незавершённых блоков текущего содержательного плана нет.
