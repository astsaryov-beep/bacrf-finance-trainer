# Сообщить замечание по тренажёру 2.3 beta

Для сообщения в групповой чат или GitHub Issues используйте такой шаблон:

- **Режим:** тренировка / пробный экзамен / каталог / повторение
- **ID или номер вопроса:**
- **Тип замечания:** неправильный ключ / неполное объяснение / неоднозначность / ошибка интерфейса / сохранение прогресса
- **Что произошло:**
- **Что ожидалось:**
- **Подтверждение (при наличии):** страница презентации или официальный источник
- **Браузер и устройство (для ошибок интерфейса):**

Если замечание касается письменного ответа, приложите собственную формулировку *без персональных данных*. Перед отправкой скриншота убедитесь, что на нём нет ФИО, подписей и личных документов.

Тренажёр является тестовой версией: ключи и объяснения могут содержать ошибки, замечания проверяются отдельно.
