# Финансовые рынки и институты — тренажёр БАЦРФ

## Дизайн 4.0 beta — тестовая ветка

**[▶ Открыть исходный работающий сайт 3.2](https://astsaryov-beep.github.io/bacrf-finance-trainer/)**

Ветка `design/v4-beta` содержит интегрированный прототип **4.0 beta** с обновлённой типографикой, главной страницей, длинными учебными материалами, мобильной навигацией и оформлением заданий. Текущий сайт GitHub Pages продолжает использовать ветку `main` и версию 3.2.

### Состав

- 219 вопросов (19 из промежуточного теста и 200 тренировочных).
- 21 учебная тема, 42 логических блока, 18 дополнительных мини-заданий.
- Поддержка тренировки, экзамена на 50 вопросов, самопроверки письменных ответов, истории и повторения ошибок.
- Локальное хранение результатов. Структура данных сохранена относительно 3.2.

### Источники

Презентации преподавателей ВШЭ определяют содержание и терминологию учебного режима. Дополнительные вопросы по программе курса помечены отдельно: 171 вопрос связан со слайдами, 48 относятся к расширенной подготовке. Внешние источники используются для проверки и уточнений.

### Проверка перед публикацией

1. Сохранить копию результатов через экспорт.
2. Пройти учебный блок, тренировку и экзамен.
3. Проверить сохранение прогресса после закрытия вкладки.
4. Проверить работу на телефоне.
5. Опубликовать 4.0 в `main` только после приёмки.
