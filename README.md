# Финансовые рынки и институты — тренажёр БАЦРФ

## [▶ ЗАПУСТИТЬ ТРЕНАЖЁР](https://astsaryov-beep.github.io/bacrf-finance-trainer/)

**Версия 5.0.1 beta · 30 учебных тем · 60 теоретических блоков · 219 вопросов основного банка · 57 подробных карточек формул**

Тренажёр работает в браузере на компьютере и телефоне. Регистрация не требуется.

### Учебный курс

- 42 блока на основе семинарских материалов ВШЭ.
- 8 дополнительных блоков на основе лекций ВШЭ.
- 10 блоков по разделу официальной программы: акции, фонды и инвестиционные риски.
- **Подробная теория:** основы, финансовый механизм, разобранные примеры, расчёты, риски и ограничения.
- **Кратко к экзамену:** индивидуальный содержательный конспект каждого блока с определениями, фактами и формулами. Универсальные инструкции вроде «повторите термины» исключены.
- 301 определение понятий, 57 раскрывающихся карточек формул с переменными, единицами измерения, числовыми примерами и ограничениями.

### Задания и экзамен

- Исходный банк из **219 заданий** сохранён без изменений по сравнению с 4.0.
- **18 дополнительных учебных заданий**. Все 237 заданий привязаны к учебным блокам.
- Пробный экзамен из 50 разных вопросов, работа над ошибками, сохранение прогресса, экспорт и импорт результатов.

### Источники и проверка

Приоритет структуры и терминологии имеют презентации преподавателей ВШЭ. Лекционные и программные дополнения отмечены отдельно. Авторские объяснения требуют предметной рецензии перед стабильным выпуском.

Проведены структурные проверки и браузерное тестирование всех 60 блоков, переключения теории и конспектов, экзамена из 50 вопросов и сохранения состояния в имитации localStorage. **Полная ручная предметная проверка и подтверждение сохранений на реальном GitHub Pages ещё требуются.** Поэтому версия носит статус beta.
