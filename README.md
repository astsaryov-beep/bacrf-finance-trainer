# Финансовые рынки и институты — интерактивный тренажёр (БАЦРФ)

**Версия: 2.3 beta.** Неофициальный учебный проект для взаимного тестирования и подготовки к экзамену. Не является продуктом НИУ ВШЭ и не содержит официального экзаменационного ключа.

## Как пользоваться

Откройте опубликованный сайт, выберите режим тренировки или пробного экзамена (50 вопросов). В банке — 219 заданий, включая восстановленные по промежуточным тестам и тренировочные авторские задания. Письменные ответы оцениваются **самим студентом по рубрике**, не автоматически ИИ.

Прогресс и результаты хранятся **только в этом браузере на этом устройстве**. Автоматической синхронизации между устройствами нет. До смены браузера, очистки его данных или обновления адреса экспортируйте прогресс через интерфейс.

## Как сообщить об ошибке

См. [FEEDBACK.md](FEEDBACK.md). Указывайте номер/ID вопроса, почему возникла ошибка и, если возможно, ссылку на подтверждающий источник. Скриншоты приветствуются, но **не прикладывайте ФИО, подписи и другие персональные данные студентов**.

## Как разместить на GitHub Pages

1. Создайте **отдельный публичный** репозиторий (например, `bacrf-finance-trainer`).
2. Загрузите в корень репозитория `index.html`, `.nojekyll`, `README.md` и `FEEDBACK.md` (не сам ZIP-архив). Ветка `main`.
3. В `Settings → Pages → Build and deployment` выберите `Deploy from a branch`, затем `main` и `/(root)`, нажмите `Save`.
4. Дождитесь публикации и откройте `https://USERNAME.github.io/bacrf-finance-trainer/` — замените `USERNAME` своим логином и название пути, если репозиторий называется иначе.
5. Для обновления сайта замените только `index.html`. Сохраните прежний файл/коммит, чтобы можно было откатиться.

GitHub Pages — публичный сайт. Код HTML, вопросы и ключи будут доступны посетителям. Исходные презентации преподавателей, фотографии заполненных тестов и персональные данные в репозиторий не включены.

Официальная инструкция: https://docs.github.com/ru/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
