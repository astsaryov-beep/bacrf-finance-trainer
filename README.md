# Финансовые рынки и институты

Независимый учебный тренажёр для подготовки по дисциплине НИУ ВШЭ БАЦРФ. Версия **5.0.7 beta**.

**[Открыть сайт](https://astsaryov-beep.github.io/bacrf-finance-trainer/)**. Для автономного запуска откройте `index.html` в браузере.

## Возможности

- 46 учебных тем, 92 теоретических блока: объяснения с нуля, механизмы, примеры, формулы с разбором каждого обозначения и экзаменационные конспекты.
- 235 заданий в основном банке, 82 дополнительных учебных задания, пробный экзамен на 50 вопросов.
- Сохранение прогресса в браузере, импорт и экспорт результатов.
- Каталог шести предоставленных PDF лекций и семинаров, привязка каждого учебного блока к названию источника и номеру слайда.
- Новые темы лекций 4–5: страхование, экономика страховщика, пенсии, НПФ и ПДС, лизинг, факторинг, форфейтинг, инвесторы и инфраструктура рынка.

## Источники

Основной учебный источник — переданные презентации дисциплины, приведённые в [SOURCES_AUDIT.md](SOURCES_AUDIT.md). Исходные PDF не публикуются в репозитории. В карточках «Источники» указан диапазон слайдов, на который опирается теория. Пояснения, расчётные примеры и задания являются самостоятельными учебными материалами, а не дословным текстом презентаций.

Нормативы, статистика рынка и условия государственных программ могут меняться; для применения проверяйте актуальные сведения Банка России и законодательство. Описание тестов — в [QA_REPORT.md](QA_REPORT.md).

## Совместимость

Идентификаторы старых 38 тем, 76 блоков и 219 вопросов сохранены. Ключи `bacrf_finance_trainer_study_v1`, `bacrf_finance_trainer_v1`, `bacrf_finance_trainer_v2_session` не менялись. При переходе с локального HTML на сайт используйте экспорт и импорт прогресса: браузеры разделяют хранилище разных адресов.

Проект не является официальной образовательной платформой НИУ ВШЭ.
