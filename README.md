# БАЦРФ — Финансовые рынки и институты

## 5.0 beta · расширенный учебный курс

**Рабочий публичный сайт остаётся на версии 4.0:** [▶ Открыть тренажёр](https://astsaryov-beep.github.io/bacrf-finance-trainer/)

**Версия 5.0 находится в этой тестовой ветке** `study/v5-beta`. Для испытаний откройте `index.html` из полного пакета релиза в браузере. Основная ветка `main` сохранена.

### Содержание 5.0

- 30 тем, 60 учебных блоков по четырём уровням: основы, механизм, применение, углублённый материал.
- 301 разбор ключевого понятия. Важные термины выделены при чтении.
- 57 формул с раскрывающимися пояснениями каждого обозначения, единиц измерения, расчётными примерами и условиями применимости.
- Все 219 вопросов основного банка привязаны к урокам. Сохранены ещё 18 учебных мини-заданий.
- Экзамен на 50 вопросов, работа над ошибками и личный прогресс.

### Откуда взят материал

1. 42 исходных блока составлены по семинарским презентациям ВШЭ.
2. 8 блоков расширяют темы финансовой системы, банков и регулирования по лекциям ВШЭ.
3. 10 блоков по акциям и коллективным инвестициям основаны на официальной программе дисциплины и помечены как дополнительные. Полных презентаций по этим темам в доступном комплекте нет.

Презентации ВШЭ определяют последовательность, терминологию и учебные акценты. Развёрнутые пояснения, примеры и формулы дополнены специально для самостоятельного обучения.

### Тестирование и выпуск

Версия требует независимой предметной рецензии расширенных объяснений, проверки на начинающих студентах и проверки сохранения прогресса на реальном сайте. Приёмка будет проводиться до переноса в `main`.
