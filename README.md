# Финансовые рынки и институты — тренажёр БАЦРФ

## 🚀 [▶ ЗАПУСТИТЬ ТРЕНАЖЁР](https://astsaryov-beep.github.io/bacrf-finance-trainer/)

**Версия 5.0 beta · 219 вопросов · 42 учебных блока · 21 формула · пробный экзамен**

Тренажёр работает в браузере на компьютере и телефоне. Регистрация и установка приложений не требуются.

### 📚 Учебный режим

- **21 учебная тема, 42 логических блока** по материалам семинаров.
- Расширенная теория от базовых понятий до продвинутого уровня с выделением ключевых определений и подготовкой к экзамену.
- **21 формула и 67 раскрывающихся подробных разборов**: обозначения, единицы измерения, порядок вычислений, числовые примеры, ограничения применения.
- Расчётные примеры и упражнения после учебных блоков.
- Справочные разборы заданий и возможность возвращаться к теории.
- Сохранение личного учебного прогресса.

### 📝 Практика и экзамен

- **219 вопросов** в основном банке: 19 восстановлены по промежуточным тестам, 200 разработаны для тренировки.
- Пробный экзамен из 50 вопросов с навигацией по заданиям.
- Проверка письменных ответов по содержательным критериям.
- Тематическое повторение, тренировка ошибок и вопросы-аналоги.

### 🆕 Что нового в 5.0 beta

- Существенно расширены все 42 теоретических блока: материалы рассчитаны на последовательное освоение темы с нуля.
- Добавлены уровни изучения, основные понятия, пояснения и акценты на экзаменационных требованиях.
- Встроены раскрывающиеся подробные разборы для 21 формулы (67 включений в теоретические блоки).
- В разборах формул раскрыты элементы, единицы измерения, порядок расчёта, примеры и ограничения.
- Сохранены банк из 219 вопросов и экзаменационный режим на 50 заданий.

### 📖 Источники

**Приоритет содержания и терминологии принадлежит презентациям преподавателей ВШЭ.** Дополнительные задания по программе курса выделяются отдельно. Внешние источники применяются для проверки и уточнений. Учебные пояснения могут обновляться после предметной проверки.

### 💾 Сохранение результатов

Прогресс хранится локально в браузере пользователя. Для переноса между браузерами и устройствами предусмотрены экспорт и импорт. Перед очисткой данных сайта сохраните резервную копию результатов.
