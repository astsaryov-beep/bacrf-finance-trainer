## 🚀 [▶ ЗАПУСТИТЬ ТРЕНАЖЁР](https://astsaryov-beep.github.io/bacrf-finance-trainer/)

**Откройте ссылку выше: тренажёр запускается прямо в браузере.** Скачивать файлы, устанавливать программы или регистрироваться не нужно.

**2.3 beta · 219 вопросов · 4 раздела курса · пробный экзамен из 50 заданий**

> 🧪 Это тестовая версия. При обнаружении ошибок будем исправлять вопросы и работу сайта. Если вместо тренажёра открывается страница 404, значит GitHub Pages ещё не опубликован — см. [настройку публикации](#для-владельца-репозитория).

### Возможности

- **Тренировка по темам** и повторение ошибок.
- **Пробный экзамен** из 50 вопросов с навигацией и отметками «вернуться».
- **Открытые ответы** с примерами и самостоятельной проверкой по критериям.
- **Сохранение прогресса** в браузере: можно закрыть вкладку и продолжить позднее.

Прогресс хранится **локально в данном браузере и на данном устройстве**; синхронизации между устройствами нет. При смене браузера или очистке его данных предварительно экспортируйте результаты.

### 🐞 Нашли ошибку или спорный ответ?

Откройте [инструкцию по отправке замечаний](FEEDBACK.md) или создайте [GitHub Issue](https://github.com/astsaryov-beep/bacrf-finance-trainer/issues/new). Укажите ID вопроса, ожидаемый результат и причину замечания; по возможности добавьте источник. Не прикладывайте фото с ФИО, подписями и другими персональными данными.

<details>
<summary><strong>Для владельца репозитория: как включить GitHub Pages и обновлять сайт</strong></summary>

1. Перейдите в [Settings → Pages](https://github.com/astsaryov-beep/bacrf-finance-trainer/settings/pages).
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку **main**, каталог **/(root)** и нажмите **Save**.
4. Дождитесь развёртывания и проверьте [ссылку на тренажёр](https://astsaryov-beep.github.io/bacrf-finance-trainer/).
5. Чтобы обновить сайт, замените `index.html`. Сохраняйте прежний коммит для отката.

GitHub Pages публикует статический HTML без собственного сервера. Код и ответы в публичном репозитории доступны всем. Исходные презентации и фотографии заполненных тестов в репозиторий не включены.

</details>
