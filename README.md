# Финансовые рынки и институты

Учебник-тренажёр для теоретической подготовки к экзамену: объяснения с нуля, примеры, формулы и вопросы с разбором.

**[Открыть тренажёр →](https://astsaryov-beep.github.io/bacrf-finance-trainer/)**

## Как заниматься

1. Откройте **«Учебный курс»** и выберите тему. Теорию можно перечитывать после завершения блока — результаты сохранятся.
2. Используйте **«Тренировка и экзамен»** для проверки знаний. Можно пропускать вопросы, возвращаться к ним и сохранять черновики. Раздел «Теория по вопросу» открывает связанные блоки; после чтения можно вернуться к упражнению.
3. Перед завершением проверьте список неотвеченных вопросов в обзоре.

В курсе 48 тем и 96 блоков. Пробный экзамен содержит 25 открытых вопросов и 25 заданий с множественным выбором. Учебные расчёты и обычные тесты сохранены в тренировке.

Прогресс хранится в браузере. Для переноса на другое устройство используйте экспорт и импорт. Перед очисткой браузера или переходом между версиями сохраните резервную копию результатов.
