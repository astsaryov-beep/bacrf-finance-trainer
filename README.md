# Финансовые рынки и институты — тренажёр БАЦРФ

## 🚀 [▶ ЗАПУСТИТЬ ТРЕНАЖЁР](https://astsaryov-beep.github.io/bacrf-finance-trainer/)

**Версия 3.2 beta · учебный режим · 219 вопросов · 4 раздела экзамена**

Тренажёр работает в браузере на компьютере и телефоне. Регистрация и установка приложений не требуются.

### 📚 Учебный режим

- **21 учебная тема и 42 логических блока** по материалам семинаров.
- **211 объяснений терминов**, развёрнутые примеры и причинно-следственные разборы.
- **93 пояснения** к заданиям для отработки теории.
- Прогресс обучения сохраняется в браузере.

### 📝 Тренировка и экзамен

- **219 заданий** в основном банке.
- **Пробный экзамен на 50 вопросов** с навигацией и отметками.
- Тренировка ошибок, тематическое повторение и вопросы-аналоги.
- Проверка письменных ответов по содержательным критериям.

### 💾 Результаты и продолжение

Прогресс хранится локально в браузере на текущем устройстве. Перенос между устройствами доступен через экспорт и импорт результатов. Перед очисткой данных браузера полезно сохранить резервную копию прогресса.

### 🧪 Бета-тестирование

Пожалуйста, сообщайте о проблемах с отображением, сохранением и оценкой ответов. Особое внимание уделяйте полноте теории перед заданиями.

[**Сообщить об ошибке или неточности**](https://github.com/astsaryov-beep/bacrf-finance-trainer/issues/new) · [Инструкция по замечаниям](FEEDBACK.md)

Укажите ID вопроса или название учебного блока, наблюдаемую проблему и браузер. По возможности приложите пояснение со ссылкой на источник. Избегайте загрузки фото с ФИО, подписями и персональными данными.

### О проекте

Неофициальный учебный проект для подготовки студентов. Проект находится в стадии бета-тестирования. Ответы и учебные пояснения могут уточняться по результатам предметной проверки. Материалы не представляют официальный экзаменационный ключ НИУ ВШЭ.
